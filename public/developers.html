Response

On success:

{
  "success": true,
  "instanceId": "6650...",
  "instanceName": "Support line",
  "messageId": "3EB0C767..."
}

On failure, you'll get a 4xx/5xx with a JSON error, e.g.:

{ "error": "Instance \"Support line\" is not connected (status: disconnected)" }
